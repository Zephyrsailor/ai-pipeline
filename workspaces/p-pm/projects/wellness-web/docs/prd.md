# PRD v0.1｜轻养生（情绪 + 睡眠）Web 应用

## 1. 项目概述

- **目标用户**：亚健康人群
- **产品目标**：通过每日情绪记录 + 睡眠分析，帮助用户发现状态波动并给出轻量建议。
- **项目约束**：
  - 1人开发
  - 1周 MVP
  - Web
  - 不做登录
  - 可接第三方 API（MVP 以可插拔接口为主）

## 2. 核心价值（MVP）

1. 用户可以每天快速记录情绪与睡眠数据
2. 系统可生成基础趋势分析（近7天）
3. 系统给出简单可执行建议（非医疗建议）

## 3. 用户故事（User Stories）

1. 作为亚健康用户，我希望每天 1 分钟记录情绪和睡眠，以便了解自己状态。
2. 作为亚健康用户，我希望看到近7天趋势图，以便判断是否在变好或变差。
3. 作为亚健康用户，我希望获得简单建议，以便第二天做出调整。

## 4. 功能范围（MoSCoW）

### Must（必须）
- 每日情绪记录（1-5分 + 可选备注）
- 每日睡眠记录（入睡时间、起床时间、睡眠时长/质量）
- 仪表盘（今日状态卡 + 近7天趋势）
- 基础分析结论（例如：情绪下降、睡眠不足提醒）
- 本地存储（LocalStorage/IndexedDB）
- API 接口层（可接情绪建议/睡眠建议 API）

### Should（应该）
- 每日提醒入口（浏览器通知可选）
- 一键补录昨天数据

### Could（可以）
- 导出近7天 JSON
- 深色模式

### Won’t（本期不做）
- 登录/账号体系
- 社交/社区
- 医疗诊断
- 可穿戴设备深度集成（先预留接口）

## 5. 核心页面

1. **首页仪表盘**
   - 今日情绪分、昨夜睡眠时长
   - 近7天趋势图（情绪线图 + 睡眠柱图）
   - 今日建议卡片

2. **记录页**
   - 情绪打分（1-5）
   - 睡眠信息录入（入睡/起床/主观睡眠质量）
   - 保存按钮（即时反馈）

3. **分析页（可与首页合并）**
   - 本周平均情绪
   - 本周平均睡眠时长
   - 风险提示（如连续3天睡眠<6h）

## 6. 验收标准（Acceptance Criteria）

1. 用户可在 60 秒内完成一次“情绪+睡眠”记录并保存成功。
2. 保存后首页统计即时更新。
3. 趋势图可正确展示近7天数据。
4. 无登录情况下刷新页面数据不丢失。
5. API 不可用时，系统可回退到本地规则建议（不报错中断）。

## 7. API设计（MVP建议）

- `POST /analyze/wellness`
  - 入参：近7天情绪与睡眠数据
  - 出参：`summary` + `tips[]` + `riskLevel`
- 若无后端：前端本地 rule-engine 先产出建议，后续再替换真实 API

## 8. 技术建议（1人1周）

- 前端：React + Vite（最快）
- 图表：ECharts/Recharts
- 存储：LocalStorage（MVP足够）
- API：fetch + adapter 封装（便于后续切换）

## 9. 开发排期（1周）

- **Day1**：项目初始化、页面骨架、数据模型
- **Day2**：记录页 + 本地存储
- **Day3**：首页仪表盘 + 7天趋势图
- **Day4**：分析逻辑（本地规则）+ 建议卡
- **Day5**：API适配层接入（Mock/真实接口）
- **Day6**：交互优化、空态/异常态处理
- **Day7**：整体测试、发布部署（Vercel/Netlify）
