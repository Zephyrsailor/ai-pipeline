# PRD v0.1｜Web 定时闹钟应用（个人使用）

## 1. 项目概述

- **项目名称**：Timed Alarm Web
- **目标用户**：个人用户（自用）
- **目标**：在网页端实现简单、稳定的闹钟提醒能力
- **平台**：Web
- **时间制式**：24 小时制

## 2. 核心需求

支持以下闹钟能力：

1. **一次性闹钟**
2. **重复闹钟**（每日/工作日等）
3. **浏览器提醒**（声音提醒）
4. **闹钟管理**
   - 新增
   - 编辑
   - 删除
   - 启用/停用开关

## 3. MVP 范围（做 / 不做）

### Must（本期必须）
- 新增闹钟（时间、类型、重复规则）
- 闹钟列表展示
- 闹钟启用/停用
- 编辑、删除闹钟
- 到点触发浏览器声音提醒
- 本地持久化（localStorage）

### Won’t（本期不做）
- 贪睡（Snooze）
- 音乐库/自定义铃声
- 多设备同步
- 账号登录
- 时区配置
- 手机推送/系统级通知

## 4. 用户故事（User Stories）

1. 作为个人用户，我希望快速新增一个闹钟，以便按时提醒自己。
2. 作为个人用户，我希望设置重复规则（一次性/重复），以便适配不同场景。
3. 作为个人用户，我希望在到点时听到提醒声，以便不漏事。
4. 作为个人用户，我希望能编辑、删除或停用闹钟，以便灵活管理。

## 5. 功能说明

### 5.1 新增闹钟
- 输入闹钟时间（24 小时制）
- 选择类型：一次性 / 重复
- 若重复：选择重复规则（如每日、工作日）

### 5.2 闹钟列表
- 展示字段：时间、类型、重复规则、状态（启用/停用）
- 支持编辑、删除、开关

### 5.3 提醒机制
- 到点触发音频播放
- 提醒可手动关闭（停止提醒按钮）

### 5.4 数据存储
- 本地存储闹钟配置
- 页面刷新后可恢复闹钟列表与状态

## 6. 验收标准（Acceptance Criteria）

1. 用户可成功新增一次性与重复闹钟
2. 用户可编辑、删除、启用/停用任意闹钟
3. 到达设定时间时，闹钟能触发声音提醒
4. 停用状态闹钟不会触发提醒
5. 刷新页面后，闹钟数据与状态保持一致
6. 全部时间显示为 24 小时制

## 7. 非功能要求

- 页面简单直观，单人可快速上手
- 核心操作（新增/编辑/删除/开关）响应流畅
- 代码结构清晰，便于后续扩展（如贪睡、通知）

## 8. 开发优先级（建议）

1. 闹钟数据模型 + 本地存储
2. 新增/列表/编辑/删除/开关
3. 到点检测与声音提醒
4. 重复规则处理
5. UI 优化与边界测试
