# pomodoro-miniapp 开发任务拆解（1周MVP）

## 0. 说明

- 项目：pomodoro-miniapp
- 周期：7 天
- 人员：1 人
- 优先级：P0（必须） > P1（有余力）
- 目标：按 PRD 完成计时与统计闭环并可提审

---

## Day 1｜项目初始化与UI骨架

### 任务

1. 初始化小程序项目（TypeScript 模板）
2. 建立目录结构（pages/core/services/utils）
3. 首页 UI 骨架：
   - 当前阶段文本
   - 倒计时占位
   - 操作按钮区
   - 今日统计卡
4. 定义基础类型与常量：
   - `Mode`、`Status`
   - `FOCUS_SEC`、`BREAK_SEC`

### 交付物

- 可运行首页
- 基础样式与组件结构

### 验收标准

- `npm run dev` 可编译通过
- 首页可正常加载，信息区完整显示

---

## Day 2｜计时状态机（核心）

### 任务

1. 实现 `TimerEngine`：
   - 状态初始化
   - 状态转移守卫
2. 实现每秒 tick 驱动与剩余时间计算
3. 实现时间格式化工具 `mm:ss`
4. 建立单例定时器机制（避免多 interval）

### 交付物

- `core/timer-engine.ts`
- `utils/time.ts`

### 验收标准

- 支持 `idle/running/paused` 状态切换
- UI 倒计时可稳定递减
- 无重复 interval 问题

---

## Day 3｜操作链路与自动切换

### 任务

1. 完成操作事件：
   - 开始、暂停、继续、结束、重置
2. 实现 focus→break 自动切换
3. 实现 break→focus 自动切换
4. 接入提醒服务（Toast，必要时振动）
5. 接入埋点事件：
   - `timer_start`/`timer_pause`/`timer_resume`
   - `focus_complete`/`break_complete`

### 交付物

- 按钮行为完整闭环
- 阶段切换提醒可见

### 验收标准

- 点击结束后本轮不计番茄
- 点击重置恢复当前阶段初始时长
- 阶段切换无卡死、无重复触发

---

## Day 4｜本地存储与前后台恢复

### 任务

1. 实现 `storage-service.ts`
   - `timer_state_v1` 保存/读取
   - `daily_stats_v1` 保存/读取
2. `onHide` 持久化关键状态
3. `onShow` 执行时间戳重算恢复
4. 增加幂等字段（`cycleId`）防重复加番茄

### 交付物

- 状态恢复完整可用
- 重启小程序后数据不丢

### 验收标准

- 切后台 1~5 分钟再回前台，剩余时间正确
- 冷启动后可读取到上次状态

---

## Day 5｜统计口径与展示完成

### 任务

1. 实现 `stats-service.ts`
2. 严格落地统计口径：
   - 仅完整 focus +1
   - `focusTotalMin = count * 25`
3. 跨天统计重置（date 校验）
4. 首页统计卡联动刷新

### 交付物

- 今日统计功能完整

### 验收标准

- 多轮测试后统计值与预期一致
- 跨天自动重置成功

---

## Day 6｜全链路测试与边界修复

### 任务

1. 测试场景覆盖：
   - 运行中暂停/继续
   - 临近结束时切后台再返回
   - 结束与重置混合操作
   - 快速连点按钮
2. 修复状态错乱、重复触发、显示延迟等问题
3. 增加按钮防抖与日志输出

### 交付物

- 稳定版候选构建

### 验收标准

- 无阻断级 bug（计时卡死/统计错乱）
- 主流程稳定可重复执行

---

## Day 7｜体验优化与提审准备

### 任务

1. 文案与视觉细节优化
2. 可选增强（P1）：
   - 震动反馈
   - 统计详情页（若时间允许）
3. 自测清单回归
4. 提审材料与版本说明准备

### 交付物

- 可提审 MVP 版本

### 验收标准

- PRD Must 全部完成
- 提审前无 P0/P1 级功能阻断

- T2 状态机与计时引擎

## 完成定义（Definition of Done）

1. 功能：PRD Must 全量完成。
2. 正确性：统计口径严格符合 PRD。
3. 稳定性：前后台恢复可靠，且无重复计数。
4. 可用性：离线可完整使用。
5. 质量：无阻断交付的问题，具备提审条件。
