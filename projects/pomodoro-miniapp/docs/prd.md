# PRD v0.1｜备考番茄钟小程序

## 1. 项目概述

- **产品名称（暂定）**：专注番茄钟
- **目标用户**：大学生备考人群
- **核心目标**：
  1. 提供稳定、无干扰的 25/5 番茄循环计时
  2. 让用户每天清楚看到专注总时长
- **项目约束**：
  - 1 人开发
  - 微信小程序
  - 1 周 MVP
  - 仅做「计时 + 统计」
  - 不做社交、白噪音、任务管理

## 2. 用户故事（User Stories）

1. 作为备考大学生，我想一键开始 25 分钟专注计时，以便立刻进入学习状态。
2. 作为备考大学生，我想在专注结束后自动进入 5 分钟休息，以便形成稳定节奏。
3. 作为备考大学生，我想看到当天累计专注时长与完成番茄数，以便评估学习投入。
4. 作为备考大学生，我想在中断时可暂停/继续，以便应对临时情况。

## 3. 功能范围（MoSCoW）

### Must（必须）
- 25 分钟专注 + 5 分钟休息循环计时器
- 一键开始 / 暂停 / 继续 / 结束
- 阶段切换提醒（专注结束、休息结束）
- 当日统计：
  - 专注总时长（分钟）
  - 完成番茄数（个）
- 本地存储（当天记录不丢失）
- 跨页面返回后计时状态正确恢复

### Should（应该）
- 重置当前轮次
- 首页显示“当前阶段 + 剩余时间 + 今日累计”

### Could（可以）
- 自定义提示文案（仅本地）
- 简单震动反馈

### Won’t（本期不做）
- 社交排行
- 白噪音/音乐
- 任务清单
- 云同步/多端同步
- 打卡社区

## 4. 核心流程

### 流程A：开始专注
打开小程序 → 点击“开始专注” → 进入 25:00 倒计时 → 专注结束提醒 → 自动切换 5:00 休息

### 流程B：循环继续
休息结束提醒 → 自动进入下一轮 25:00 专注（MVP 采用自动进入）

### 流程C：查看统计
进入统计区域 → 查看“今日专注总分钟数 + 今日完成番茄数”

## 5. 页面结构（MVP）

1. **首页（唯一主页面）**
   - 当前阶段：专注/休息
   - 大号倒计时（mm:ss）
   - 操作按钮：开始、暂停、继续、结束、重置
   - 今日统计卡片：今日专注分钟、今日番茄数

2. **（可选）统计详情页**
   - 今日累计专注时长
   - 今日完成番茄数
   - （可选）最近7天简表（若工期紧可不做）

## 6. 验收标准（Acceptance Criteria）

### A. 计时准确性
- 开始后倒计时每秒递减，误差可控（前台可见状态）
- 专注阶段默认 25:00，休息阶段默认 05:00
- 阶段切换逻辑正确，无卡死、无重复触发

### B. 状态控制
- 支持暂停与继续，继续后从暂停点恢复
- 点击结束后，本轮不计入“完成番茄”
- 点击重置后，当前轮回到阶段初始时长

### C. 统计口径
- 仅在**完整完成一个25分钟专注阶段**后，番茄数 +1
- 当日专注总时长 = 完成番茄数 × 25（MVP口径）
- 页面刷新/重进后，今日统计仍可正确读取

### D. 稳定性
- 小程序切后台再返回，计时状态可恢复（基于时间戳计算剩余）
- 无网络情况下可正常使用全部 MVP 功能

## 7. 数据设计（本地存储）

### Storage Key 建议
- `timer_state_v1`
- `daily_stats_v1`

### timer_state_v1
- `mode`: `"focus" | "break"`
- `status`: `"idle" | "running" | "paused"`
- `durationSec`: number（当前阶段总秒数）
- `remainingSec`: number
- `startedAt`: number | null（时间戳）
- `pausedAt`: number | null

### daily_stats_v1
- `date`: `YYYY-MM-DD`
- `focusPomodoroCount`: number
- `focusTotalMin`: number

## 8. 埋点与指标（轻量）

### 关键事件
- `timer_start`
- `timer_pause`
- `timer_resume`
- `focus_complete`
- `break_complete`

### MVP成功指标（上线后1周）
- 人均每日完成番茄数 ≥ 4
- 用户连续使用3天比例 ≥ 30%
- 计时流程异常率（崩溃/错乱） < 1%

### Day 5

### Day 6

### Day 7
