# PRD v0.1｜Snake Mini Game（Web）

## 1. 项目概述

- **项目名称**：snake-mini-game
- **目标用户**：个人娱乐（自己玩）
- **平台**：Web（桌面浏览器）
- **开发资源**：1人开发
- **核心目标**：实现可流畅游玩的基础贪吃蛇体验（键盘操作）

## 2. 产品目标与边界

### 目标
- 提供一个打开即玩的基础贪吃蛇小游戏
- 支持键盘控制、得分、死亡结束、重新开始

### 本期边界（明确不做）
- 不做账号系统
- 不做排行榜
- 不做皮肤/关卡/音效
- 不做移动端触控操作
- 不做联网和后端服务

## 3. 用户故事（User Stories）

1. 作为玩家，我希望通过键盘方向键控制蛇移动。
2. 作为玩家，我希望吃到食物后蛇变长并加分。
3. 作为玩家，我希望撞墙或撞到自己时游戏结束。
4. 作为玩家，我希望游戏结束后能快速重新开始。

## 4. 功能范围（MoSCoW）

### Must（必须）
- 游戏画布（固定网格）
- 蛇自动移动
- 方向控制（↑ ↓ ← →）
- 食物随机生成
- 吃食物后蛇身增长 + 分数增加
- 碰撞检测（墙体、自身）
- Game Over 状态显示
- 重新开始（按键或按钮）

### Should（应该）
- 开始前提示操作说明
- 当前分数显示

### Could（可选）
- 最高分（本地 localStorage）

### Won’t（本期不做）
- 音效、皮肤、难度系统、排行榜、移动端适配

## 5. 交互与规则定义

- 初始方向：向右
- 初始蛇长：3格
- 地图大小：20x20 网格
- 食物：地图内随机空位置刷新
- 得分规则：每吃1个食物 +1分
- 刷新频率：120~180ms/步（MVP先固定）
- 键盘限制：禁止瞬间反向（例如向右时不能直接按左）

## 6. 页面结构（单页）

1. 标题区：`Snake Mini Game`
2. 分数区：`Score: N`
3. 游戏区：Canvas
4. 状态区：开始提示 / 游戏中 / Game Over
5. 操作区：`Restart` 按钮（可选，另支持按空格重开）

## 7. 验收标准（Acceptance Criteria）

1. 打开页面后可开始游戏，蛇自动移动。
2. 方向键控制有效，且不允许直接反向。
3. 蛇吃到食物后长度+1，分数+1，食物重新刷新。
4. 撞墙或撞自己时立即结束并显示 `Game Over`。
5. 结束后可通过 Restart（按钮或空格）重开，分数归零、状态重置。
6. 在主流桌面浏览器（Chrome）可稳定运行，无明显卡顿。

## 8. 技术方案（MVP）

- 前端：原生 HTML + CSS + JavaScript
- 渲染：`<canvas>`
- 数据结构：
  - `snake: Array<{x,y}>`
  - `food: {x,y}`
  - `direction: {x,y}`
  - `score: number`
  - `gameState: ready | running | over`
- 循环：`setInterval(gameTick, speed)`（MVP足够）

## 9. 开发计划（1人 / 1~2天）

### Day 1
- 搭页面与 canvas
- 实现蛇移动、方向控制、食物生成
- 实现得分与碰撞检测

### Day 2
- 实现 game over 与 restart
- 修复边界 bug
- 基础样式优化与自测
