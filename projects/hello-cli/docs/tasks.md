# hello-cli 开发任务拆解（MVP）

## 0. 说明

- 项目：hello-cli
- 开发模式：最小可用实现
- 目标：完成本地命令 `hello-cli <name>` 并输出固定问候语

---

## 1. 任务列表

### T1. 初始化项目与入口映射

- 创建/更新 `package.json`
- 配置 `name = hello-cli`
- 配置 `bin` 映射到 `./index.js`

**验收**：具备命令入口配置，可调用脚本。

### T2. 实现 CLI 主逻辑（单文件）

- 创建 `index.js`
- 增加 shebang：`#!/usr/bin/env node`
- 读取 `process.argv[2]`
- 输出固定格式：`Hello, <name>!`

**验收**：输入参数后能按固定格式输出。

### T3. 本地运行验证

- 用中文名验证：`hello-cli 张三`
- 用英文名验证：`hello-cli Alice`
- 检查输出是否严格匹配模板

**验收**：两个样例均通过。

### T4. 交付检查

- 检查执行速度是否即时
- 检查是否引入超范围功能（help、交互输入等）

**验收**：符合 PRD 边界，无额外功能。

---

## 2. 建议执行顺序

按 `T1 -> T2 -> T3 -> T4` 顺序推进，预计可在短周期内完成。

---

## 3. Definition of Done

满足以下全部条件即完成：

1. 本地可执行 `hello-cli <name>`。
2. 输出严格为 `Hello, <name>!`。
3. 中文/英文示例均通过。
4. 不包含 PRD 明确不做的扩展能力。
